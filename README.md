# ICBC_Cup

ICBC Cup creative finance entry by Zibo Rui: "E-Dimension Symbiosis" — a Gen-Z IP banking ecosystem on ICBC's large language model, covering debit-credit separation, dynamic digital card art, AI companion service, and full-lifecycle anti-dormancy operations.

E-Dimension Symbiosis (e 次元共生) — an award submission for the ICBC Cup. This project reimagines retail banking for Gen-Z through an IP-driven financial ecosystem: separating debit and credit products to control risk, generating dynamic 3D digital card art with a large language model, deploying an IP-styled AI companion for daily finance, and running life-cycle anti-dormancy mechanisms to keep engagement compliant and sustainable.
